我在 GitHub 上持续维护与智能体、自动化相关的项目，经历集中在智能体工作流编排、工具链集成、自动化脚本与工程化落地。目前代表项目正在建设中，欢迎交流与合作。

## 关注方向

- **智能体工作流搭建**：多智能体编排、任务分解、工具调用与状态机管理
- **LLM 应用工程化**：Prompt 工程、RAG 管线、可观测性与错误恢复
- **自动化与集成**：CI/CD、脚本化流程、第三方服务编排
